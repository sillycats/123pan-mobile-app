## 功能特性

### 文件管理
- 文件列表浏览，单击文件夹进入，长按弹出操作菜单
- 文件夹操作：打开、下载、分享、详细信息、移动、复制、重命名、删除、去重此目录
- 文件操作：播放/预览、下载、分享、详细信息、移动、复制、重命名、删除
- 多选批量操作（整理模式）：批量移动、批量复制、批量删除
- 文件类型图标按类型着色（文件夹/图片/视频/音频/文档/APK等）
- 文件列表滚动分页加载
- 排序（按文件名/大小/创建时间/修改时间）
- 文件列表显示时间和文件大小
- 右上角一键刷新

### 上传下载
- 上传文件 / 文件夹（保留目录结构）
- 单文件下载、文件夹批量打包下载（自动加 .zip 后缀）
- 下载进度显示，传输记录管理
- 上传/下载时自动保持屏幕常亮
- 自定义下载缓存目录
- 删除传输记录时可选同时删除已下载文件

### 预览
- 图片/视频/音频在线播放
- 文本文件查看
- PDF/Word/Excel 预览
- HTML 文件网页预览（支持网页/源码切换）

### 分享与直链
- 创建分享（随机提取码/自定义提取码/无提取码）
- 我的分享管理、接收分享
- 分享链接自动拼接提取码
- **直链解析**：粘贴123云盘分享链接 → 解析文件列表 → 点击文件获取下载直链 → 生成直链二维码

### 回收站
- 恢复文件/文件夹到原位置
- 恢复到指定目录（自动移动）
- 彻底删除单个/批量文件
- 清空回收站（二次确认）
- 删除触发安全验证时App内完成验证

### 文件去重
- 全盘文件去重（设置页）
- 指定文件夹去重（长按文件夹/底部工具栏）
- 按文件名+大小多维判重

### 其他
- 日间/夜间/跟随系统主题
- 网页端管理（App内打开桌面版网页）
- 离线下载（磁力/HTTP 链接）
- 多账号管理
- 自动更新检测
